# 지하철 땅따먹기 🚇

서울 지하철 1~9호선 노선도 위에서 벌이는 턴제 영토 전략 게임.
실제 역의 특성(도심/변두리, 지상/지하/심층, 한강 도하)이 게임 규칙에 반영됩니다.

## 게임 방법

- 시작할 때 **본진 역**을 하나 고릅니다 (상대 본진과 6정거장 이상 떨어져야 함).
- 매턴 점령한 역들이 **AP(행동 포인트)** 를 생산하고, AP로 인접 역을 점령합니다.
- AP 수확은 자기 턴 종료 시 이뤄지며, 보유 상한은 `10 + 2 × 점령 역 수`입니다.

### 역 특성

| 특성 | 효과 |
|---|---|
| 도심핵심 / 보통 / 변두리 | 기본 생산 3 / 2 / 1 AP |
| 환승역 | 노선 1개 추가당 생산 +1 |
| 지상역 (점선 테두리) | 방어 0 — 뚫기 쉬움 |
| 지하역 | 방어 1 |
| 심층역 (두꺼운 테두리) | 방어 2 — 요새 |
| 본진 | 생산 +1, 방어 +2 |

- 점령 비용: `2 + 방어력` AP (적 점령지는 +1)
- 🌊 **한강 도하** (한강철교·당산철교·잠실철교·동호대교·동작대교·여의나루/광나루 하저터널·청담대교): 비용 ×1.5

### 게임 모드

- **상대**: 🤖 AI 대전 (쉬움/보통/어려움) 또는 👥 2인 로컬
- **승리 조건**: 🚩 본진 함락전 (상대 본진 점령 시 즉시 승리) 또는 🗺️ 정복전 (제한 라운드 후 다수 역 보유 승리)

## 맵 범위

| 노선 | 구간 |
|---|---|
| 1호선 | 도봉산 ~ 노량진 |
| 2호선 | 본선 순환 전체 |
| 3호선 | 지축 ~ 오금 |
| 4호선 | 당고개 ~ 사당 |
| 5호선 | 방화 ~ 상일동 + 마천 지선 |
| 6호선 | 응암 순환 + 신내 방면 |
| 7호선 | 장암 ~ 온수 |
| 8호선 | 암사 ~ 모란 |
| 9호선 | 개화 ~ 중앙보훈병원 |

환승역 중복 제거 시 총 **267역**, 한강 도하 8곳. 좌표는 실제 지리 기반의
도식화 좌표이고, 깊이·등급 태그는 게임 밸런스를 위한 근사치입니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 정적 빌드 (dist/) — 서버 불필요, GitHub Pages 등에 바로 배포 가능
```

React + TypeScript + Canvas (Vite). 게임 로직은 `src/game/engine.ts`의
순수 함수(상태 + 행동 → 새 상태)로 구현되어 있어, 이후 온라인 모드를 붙일 때
그대로 재사용할 수 있습니다.
