# 지하철 땅따먹기 🚇

수도권 전철 전 노선(649역) 위에서 벌이는 턴제 영토 전략 게임.
실제 역의 특성(도심/변두리, 지상/지하/심층, 한강 도하)이 게임 규칙에 반영됩니다.

## 게임 방법

- **드래프트**: 각자 10AP를 갖고 번갈아 시작 역들을 고릅니다. 역당 기본 1AP,
  환승역은 노선 수만큼 가산(2노선 +1, 3노선 +2, …), 내 영토와 떨어진 역은 +1.
  첫 번째로 고른 역이 **본진**이 되고(상대 본진과 8정거장 이상), 남은 AP는
  게임으로 이월됩니다.
- 매턴 점령한 역들이 **AP(행동 포인트)** 를 생산하고, AP로 인접 역을 점령합니다.
- AP 수확은 자기 턴 종료 시 이뤄지며, 보유 상한은 `10 + 2 × 점령 역 수`입니다.

### 역 특성

| 특성 | 효과 |
|---|---|
| 도심핵심 / 보통 / 변두리 | 기본 생산 3 / 2 / 1 AP |
| 환승역 | 노선 1개 추가당 생산 +1 (최대 +3) |
| 지상역 (점선 테두리) | 방어 0 — 뚫기 쉬움 |
| 지하역 | 방어 1 |
| 심층역 (두꺼운 테두리) | 방어 2 — 요새 |
| 본진 | 생산 +1, 방어 +2 |

- 점령 비용: `2 + 방어력` AP (적 점령지는 +1)
- ⚔️ **포위**: 적 역이 내 역 2곳과 인접하면 비용 절반(내림), 3곳 이상이면 무료
- 📉 **수확 체감**: 실수령 AP = ⌈수입^0.8⌉ — 후반 인플레 완화
- 🛡 **요새화**: 내 역에 3AP 투자해 방어 +1 (역당 최대 +2, 뺏기면 파괴)
- 🚧 **바리케이드**: 내 역과 맞닿은 구간에 3AP로 설치 — 그 구간 통과 공격 +3AP,
  한 번 뚫리면 소멸 (설치자 본인에겐 무효)
- 🚩 함락전/정복전에서 본진이 함락된 플레이어는 탈락하며 **남은 영토는 정복자가 흡수**
- 🌊 **한강 도하** 12곳 (한강철교·당산철교·잠실철교·동호대교·동작대교·청담대교·마곡대교와
  5호선/8호선/수인분당선/서해선 하저터널): 비용 ×1.5

### 게임 모드

- **상대**: 🤖 AI 대전 (쉬움/보통/어려움), 🌐 온라인 (2~4인, P2P), 👥 2인 로컬
- **승리 조건**:
  - 🚩 본진 함락전 — 상대 본진 점령 시 즉시 승리
  - 🗺️ 정복전 — 제한 라운드 후 다수 역 보유 승리 (본진 함락 시 즉시 승리)
  - ⚔️ 전멸전 — 상대의 모든 역을 점령해야 승리. 본진을 잃어도 게임은 계속된다

환승역 중복 제거 시 총 **649역 · 24개 노선**, 한강 도하 12곳. 좌표는 실제 지리
기반의 도식화 좌표이고, 깊이·등급 태그는 게임 밸런스를 위한 근사치입니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 정적 빌드 (dist/) — 서버 불필요, GitHub Pages 등에 바로 배포 가능
```

React + TypeScript + Canvas (Vite). 게임 로직은 `src/game/engine.ts`의
순수 함수(상태 + 행동 → 새 상태)로 구현되어 있어, 이후 온라인 모드를 붙일 때
그대로 재사용할 수 있습니다.
